YouTube Clone

A responsive front-end recreation of the YouTube home page, with a collapsible sidebar, category filters, live search and an in-page video player.

Open live demo

Overview

I built this project to practise structuring a real-world interface from scratch using HTML, CSS and JavaScript. The page follows the layout people already know from YouTube: a fixed top bar with search, a navigation sidebar, a row of category filters and a grid of video cards.

It is a front-end-only project. It uses embedded YouTube videos and has no backend, accounts or API key, which kept the focus on layout, responsiveness, state handling and performance.

Preview

How it works

Video data lives in a single JavaScript array, and one render function builds the grid from it. The category buttons and the search box both feed the same filter, so they work together: choosing "Gaming" and typing a keyword narrows the results by both.

Cards show thumbnails rather than live players. Clicking a card opens a modal that loads the YouTube player only at that moment and unloads it on close, so playback stops and the page stays light. Real titles and channel names are fetched from YouTube's public oEmbed endpoint, with placeholder text as a fallback if the request fails.

Technical highlights

  • Responsive layout: a Bootstrap 5 grid that moves from one to four columns, and a sidebar that collapses on desktop and slides in over the content on tablets and phones.
  • Performance: thumbnails are lazy-loaded, and the player iframe is created only on demand instead of embedding every video up front.
  • Safe rendering: text fetched from an external source is escaped before it is inserted into the page.
  • Accessibility: labelled icon buttons, keyboard-focusable cards, visible focus states and reduced-motion support.
  • Maintainable structure: markup, styles and behaviour are split into separate files, with the video list kept as data so new videos can be added without touching the layout.
